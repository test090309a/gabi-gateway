🖥️ Shell-Befehle
Für komplexere Operationen kannst du direkt Shell-Befehle verwenden:

Windows
text
/shell dir
/shell dir *.py
/shell dir /s
/shell ipconfig /all
/shell systeminfo
/shell tasklist
/shell taskkill /F /IM notepad.exe
/shell echo "Hallo" > test.txt
/shell type test.txt
/shell del test.txt
Linux/macOS
text
/shell ls -la
/shell ls *.py
/shell ps aux
/shell killall firefox
/shell echo "Hallo" > test.txt
/shell cat test.txt
/shell rm test.txt
/shell df -h
/shell free -h
/shell ifconfig
Android (Termux)
text
/shell ls -la
/shell ps
/shell pm list packages
/shell dumpsys battery
/shell df -h
/shell am start -n com.android.chrome/com.google.android.apps.chrome.Main
Pipes & Redirection
text
/shell dir | findstr ".py"
/shell echo "Zeile 1" > test.txt && echo "Zeile 2" >> test.txt
/shell type test.txt | findstr "Zeile"
