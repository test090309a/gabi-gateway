### 🤖 GABI (2026-03-20 19:48)

Hier ist ein Beispiel für einen HTML-Code einer Landing Page:
```html
<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Meine Landing Page</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>
    <nav>
      <ul>
        <li><a href="#">Über uns</a></li>
        <li><a href="#">Produkte</a></li>
        <li><a href="#">Kontakt</a></li>
      </ul>
    </nav>
  </header>
  <main>
    <section id="hero">
      <h1>Willkommen auf unserer Landing Page!</h1>
      <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit. Mauris euismod enim ut libero mollis tempor.</p>
    </section>
    <section id="features">
      <h2>Features</h2>
      <ul>
        <li>Lorem ipsum dolor sit amet, consectetur adipiscing elit.</li>
        <li>Mauris euismod enim ut libero mollis tempor.</li>
        <li>Vivamus elementum nunc sed lacus accumsan, vitae aliquet leo sodales.</li>
      </ul>
    </section>
    <section id="call-to-action">
      <h2>Jetzt loslegen!</h2>
      <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit. Mauris euismod enim ut libero mollis tempor.</p>
      <button>Kaufen</button>
    </section>
  </main>
  <footer>
    <p>&copy; Meine Landing Page 2023</p>
  </footer>
  <script src="script.js"></script>
</body>
</html>
```
Dieser Code erstelt eine einfache Landing Page, die eine Navigation mit drei Links hat, einen Hero-Abschnitt mit einem Haupttitel und einer kurzen Beschreibung, einen Abschnitt mit verschiedenen Features und einen Abschnitt mit einem Anruf zur Aktion. Der CSS-Code kann unter "style.css" definiert werden, der JavaScript-Code kann unter "script.js" definiert werden.
