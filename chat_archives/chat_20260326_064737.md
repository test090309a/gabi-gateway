def fibonacci(n):
    if n <= 0:
        return "Eingabe muss eine positive Ganzzahl sein."
    elif n == 1:
        return 0
    elif n == 2:
        return 1
    else:
        a, b = 0, 1
        for _ in range(2, n):
            a, b = b, a + b
        return b

```html
<!DOCTYPE html>
<html>

	<style>
		.galerie {

		</div>
	</div>

```

Dieses Beispiel verwendet HTML und CSS, um eine einfache Bildergalerie zu erstellen. Die Bilder werden in einer flexiblen Box angeordnet, und jedes Bild wird in eine separate Box gesetzt. Die Bilder werden mit `object-fit: cover` auf die Box angepasst, um sicherzustellen, dass sie vollständig angezeigt werden.

Wenn du dieses Beispiel verwenden möchtest, ersetze `bild1.jpg`, `bild2.jpg` usw. durch die tatsächlichen Dateinamen deiner Bilder.

```html
<!DOCTYPE html>
<html>
<head>
	<title>Bildergalerie</title>

</head>
<body>
	<div class="galerie">
		<a href="bild1.jpg" data-lightbox="galerie">
			<img src="bild1.jpg" alt="Bild 1">
		</a>
		<a href="bild2.jpg" data-lightbox="galerie">
			<img src="bild2.jpg" alt="Bild 2">
		</a>
		<a href="bild3.jpg" data-lightbox="galerie">
			<img src="bild3.jpg" alt="Bild 3">
		</a>
	</div>
	
	<script src="lightbox.js"></script>
</body>
</html>
```

In diesem Beispiel wird die Lightbox-Bibliothek verwendet, um eine interaktive Bildergalerie zu erstellen. Die Bilder werden mit einem Link versehen, und wenn der Nutzer auf einen Link klickt, wird das Bild in einer Lightbox angezeigt.
