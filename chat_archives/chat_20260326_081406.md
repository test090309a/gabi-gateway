Hier ist ein Beispiel für eine einfache Bildgalerie in HTML, CSS und JavaScript:
```html
<!-- index.html -->
<!DOCTYPE html>
<html>
<head>
  <title>Bildgalerie</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="galerie">
    <img src="bild1.jpg" alt="Bild 1">
    <img src="bild2.jpg" alt="Bild 2">
    <img src="bild3.jpg" alt="Bild 3">
    <!-- weitere Bilder hinzufügen -->
  </div>
  <script src="script.js"></script>
</body>
</html>
```

```css
/* style.css */
.galerie {
  display: flex;
  flex-wrap: wrap;
  justify-content: center;
}

.galerie img {
  margin: 10px;
  width: 200px;
  height: 150px;
  object-fit: cover;
  border: 1px solid #ccc;
  box-shadow: 0 0 10px rgba(0, 0, 0, 0.2);
}
```

```javascript
// script.js
document.addEventListener("DOMContentLoaded", function () {
  const galerie = document.querySelector(".galerie");
  const bilder = galerie.children;

  // Bild-Überlappung vermeiden
  galerie.addEventListener("click", function (event) {
    if (event.target.tagName === "IMG") {
      const bild = event.target;
      const index = Array.prototype.indexOf.call(bilder, bild);
      const overlay = document.createElement("div");
      overlay.classList.add("overlay");
      overlay.style.backgroundImage = `url(${bild.src})`;
      overlay.style.backgroundSize = "cover";
      overlay.style.backgroundPosition = "center";
      overlay.style.width = "100%";
      overlay.style.height = "100%";
      overlay.style.position = "absolute";
      overlay.style.top = "0";
      overlay.style.left = "0";
      overlay.style.zIndex = "1";
      galerie.appendChild(overlay);
      overlay.addEventListener("click", function () {
        overlay.remove();
      });
    }
  });
});
```
Dieses Beispiel erstellt eine einfache Bildgalerie mit einer Übersichtsansicht und einer Detailansicht für jedes Bild. Die Bilder werden mit CSS gestaltet, und die Übersichtsansicht wird mit JavaScript erstellt.

Bitte beachte, dass du die Bilder `bild1.jpg`, `bild2.jpg`, usw. ersetzen musst, um die Beispiel-Code zu verwenden.
